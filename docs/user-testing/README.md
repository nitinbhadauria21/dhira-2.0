# Dhira — team user testing

Kit for running teammate usability tests and collecting feedback in Google Forms / Sheets.

| File | Who | What |
|---|---|---|
| [TEST_SCRIPT.md](./TEST_SCRIPT.md) | Testers | 20–30 min walkthrough |
| [GOOGLE_FORM_QUESTIONS.md](./GOOGLE_FORM_QUESTIONS.md) | Facilitator | Exact questions to paste into Google Forms |
| [FACILITATOR_NOTES.md](./FACILITATOR_NOTES.md) | Facilitator | Create Form, link Sheet, read scores |
| [SHEET_COLUMNS.csv](./SHEET_COLUMNS.csv) | Facilitator | Header row if logging manually in a Sheet |

**Quick start:** open `FACILITATOR_NOTES.md` → build the Form from `GOOGLE_FORM_QUESTIONS.md` → share Form + `TEST_SCRIPT.md` with the team.
